# Kingdom Sermon Intelligence

A sermon-to-resource workspace for churches. Turn sermon transcripts into editable summaries, outlines, Scripture references, devotionals, discussion guides, and social content while keeping the original message central and requiring human review.

## MVP

- Sermon transcript and metadata workspace
- Editable resource drafts
- Scripture reference review flags
- Copy and export workflows
- Human approval before anything is published

## Planned stack

Next.js, TypeScript, and a Vercel deployment. Initial version prioritizes a usable front end; AI provider and persistent storage integrations can be added after the core workflow is in place.
